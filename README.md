# Neural Network From Scratch

This repository serves as a record of my journey toward building a neural network from scratch. Instead of treating machine learning as a collection of libraries and APIs, my goal is to understand the principles that make it work by implementing each concept myself.

The repository is continuously updated as I learn new topics, revisit previous implementations, and improve my understanding.

## Purpose

The main goals of this repository are to:

* Learn the mathematical foundations behind neural networks.
* Implement core algorithms from scratch in Python.
* Keep track of my progress over time.
* Build intuition by experimenting with concepts instead of treating them as black boxes.

## Current Focus

Some of the topics explored throughout this repository include:

* Python
* NumPy
* Vectors and matrices
* Linear algebra
* Calculus
* Activation functions
* Cost and loss functions
* Gradient descent
* Backpropagation
* Forward propagation

Additional topics will be added as my learning progresses.

## About This Repository

This is not intended to be a machine learning framework or a polished project. It is a collection of notes, implementations, experiments, and exercises that reflect my learning process.

Some code may be rewritten or replaced as I gain a better understanding of the concepts. I prefer improving previous work rather than leaving early implementations untouched.

## Resources

The material in this repository is based on a variety of learning resources, including books, documentation, lectures, and educational videos. Every implementation is written by me as part of understanding the underlying ideas.

## Final Goal

The end goal is to build a complete neural network from scratch, understanding every step—from the mathematics behind it to the final implementation—without relying on high-level machine learning libraries.
